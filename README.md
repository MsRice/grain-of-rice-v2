## Overview

The Grain of Rice is a portfolio site designed to showcase engineering work, technical thinking, and continuous learning. It serves as a living document — evolving with every project, conference, certification, and lesson learned.

### Key Pages

- `/` — Homepage with featured projects and capabilities
- `/patricemaxwell` — Networking landing page (digital business card)
- `/now` — Current focus, projects, and learning
- `/projects` — Engineering case studies

## Built With

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Vercel (deployment)

## How to Use

Clone and run locally:

```bash
git clone https://github.com/MsRice/the-grain-of-rice.git
cd the-grain-of-rice
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
